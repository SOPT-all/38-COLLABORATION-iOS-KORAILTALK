## 🚄 Convention
### Branch
`종류/#이슈번호`
```
feat/#1
```

### Tag
| 태그 | 사용 |
|-----------|------|
| `feat` | 새로운 기능 구현 시 사용 |
| `fix` | 버그나 오류 해결 시 사용 |
| `chore` | 코드 수정, 내부 파일 수정, 애매한 것들이나 잡일 시 사용 |
| `add` | 사진 등 에셋이나 라이브러리 추가 시 사용 |
| `del` | 쓸모없는 코드 삭제 시 사용 |
| `docs` | README나 WIKI 등의 문서 개정 시 사용 |
| `refactor` | 기존 코드를 전면 수정 시 사용 |
| `setting` | 프로젝트 관련 설정 변경 시 사용 |
| `merge` | 작업 브랜치를 develop 브랜치에 merge 시 사용 |

### Commit Message
`[종류] #이슈번호 - 작업 이름`

```
[feat] #1 - 메인 UI 구현
```
